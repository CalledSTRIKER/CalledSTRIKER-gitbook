# WebMap

[WebMap](https://github.com/SabyasachiRana/WebMap) is a web-based Nmap dashboard with 100K+ Docker pulls. A critical unauthenticated RCE vulnerability (CVSS 9.8) was discovered affecting its default deployment, allowing any remote attacker to execute arbitrary commands as root with no credentials required.

Full technical writeup and proof of concept will be published following a 30-day responsible disclosure window.
